# Check Auto — landing (Robokassa)

Vue 3 + Vite + Tailwind CSS 4 сайт для ООО «ЧЕК-АВТО».

## Страницы

| Путь | Содержание |
|------|------------|
| `/` | Услуги и цены, контакты, ссылки на документы |
| `/contacts` | Контакты и реквизиты |
| `/offer` | Публичная оферта |
| `/refund` | Условия оплаты и возврата |
| `/privacy` | Политика конфиденциальности |
| `/terms` | Пользовательское соглашение |

Реквизиты (ИНН, ОГРН, адрес, телефон, email) выводятся в footer на всех страницах.

## Запуск

```bash
cd web
npm install
npm run dev
```

Сборка: `npm run build`
